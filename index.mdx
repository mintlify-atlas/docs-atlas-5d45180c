Arclight is a Bukkit server implementation built on top of Minecraft mod loaders. Instead of choosing between Bukkit plugins and Forge/Fabric mods, Arclight lets you run both at the same time on a single server. It supports Minecraft 1.20 and 1.21 across three platforms: Forge, NeoForge, and Fabric.

## How Arclight works

Arclight uses the [Mixin](https://github.com/SpongePowered/Mixin) framework to inject Bukkit/CraftBukkit behavior directly into the Minecraft server at runtime. It also includes a runtime class remapper that translates obfuscated CraftBukkit class references used by plugins into the correct mod-loader namespaced names — no plugin recompilation required.

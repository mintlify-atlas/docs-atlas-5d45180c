---
title: "Get started with Arclight in 5 minutes"
description: "Download Arclight, start your server, and confirm that a Bukkit plugin and a Minecraft mod are both running in under five minutes."
---

This guide takes you from zero to a running Arclight server with both a Bukkit plugin and a Minecraft mod loaded. By the end you will have confirmed that the two ecosystems coexist on a single server.

For a deeper look at any individual step, see the [installation guide](/installation).

<Steps>
  <Step title="Download the Arclight JAR">
    Go to [https://arclight.izzel.io](https://arclight.izzel.io) and download the JAR for your platform. The filename tells you the platform and Minecraft version:

    | File | Platform |
    |---|---|
    | `arclight-forge-1.21.1.jar` | Forge |
    | `arclight-neoforge-1.21.1.jar` | NeoForge |
    | `arclight-fabric-1.21.1.jar` | Fabric |

    Create a new directory for your server and move the JAR into it. Keep it isolated — Arclight writes many files and subdirectories alongside the JAR.
  </Step>

  <Step title="Run the server for the first time">
    Open a terminal in your server directory and launch the JAR. Replace the filename with the one you downloaded:

    ```bash
    java -jar arclight-forge-1.21.1.jar nogui
    ```

    The server will download the mod loader runtime and Minecraft server files. This takes a few minutes on the first run. When it stops and prints something like `You need to agree to the EULA`, that is expected — continue to the next step.

    <Note>
      Java 21 or later is required. Run `java -version` to check. If you see a version below 21, install a Java 21 JDK before continuing.
    </Note>
  </Step>

  <Step title="Accept the EULA">
    Open the `eula.txt` file that was generated in your server directory and change the last line from `false` to `true`:

    ```properties
    eula=true
    ```

    Save the file. You will not be able to proceed past the startup screen until you do this.
  </Step>

  <Step title="Start the server again">
    Run the same launch command again:

    ```bash
    java -jar arclight-forge-1.21.1.jar nogui
    ```

    This time the server completes its startup. Watch the console for the line:

    ```
    Done (X.XXXs)! For help, type "help"
    ```

    When you see it, your server is running. You can connect to it from Minecraft at `localhost`.
  </Step>

  <Step title="Install a Bukkit plugin">
    Stop the server with the `stop` command in the console (or `Ctrl+C`).

    Download any Bukkit/Spigot-compatible plugin JAR — for example, a permissions plugin or a chat formatter. Drop the `.jar` file into the `plugins/` directory inside your server directory:

    ```
    my-arclight-server/
    └── plugins/
        └── YourPlugin.jar
    ```

    Start the server again. Look for your plugin's name in the startup logs:

    ```
    [INFO] [YourPlugin] Enabling YourPlugin v1.0
    ```

    <Tip>
      Run `plugins` in the server console after startup to see a list of all loaded plugins and their status. A green name means the plugin loaded successfully.
    </Tip>
  </Step>

  <Step title="Install a mod">
    Stop the server again. Mods go in the `mods/` directory alongside `plugins/`. Place your mod JAR there:

    ```
    my-arclight-server/
    ├── mods/
    │   └── your-mod.jar
    └── plugins/
        └── YourPlugin.jar
    ```

    <Note>
      Make sure the mod you install is compatible with your chosen platform (Forge, NeoForge, or Fabric) and the correct Minecraft version (1.21.1). Loading a mod built for the wrong platform or version will produce an error on startup.
    </Note>

    Start the server once more. The mod loader picks up the mod during its initialization phase, before Bukkit loads plugins.
  </Step>

  <Step title="Verify both are loaded">
    With the server running, check the startup logs to confirm both your plugin and your mod loaded successfully.

    For the plugin, look for its enable message:

    ```
    [INFO] [YourPlugin] Enabling YourPlugin v1.0
    ```

    For the mod, look for its registration line (the exact format depends on the platform and the mod):

    ```
    [modid] Loaded mod "Your Mod" v1.0
    ```

    <Tip>
      If either the plugin or mod fails to load, the console will print a warning or error with the reason. Common issues are covered in [common errors](/troubleshooting/common-errors). For plugin-specific compatibility notes, see [plugin compatibility](/compatibility/plugins). For mod-specific notes, see [mod compatibility](/compatibility/mods).
    </Tip>

    You can also run `plugins` in the console to list all loaded plugins, and check your platform's mod list command (`/forge mods`, `/neoforge mods`, or `/fabric` depending on your platform) to see loaded mods.
  </Step>
</Steps>

## What to do next

Now that your server is running with both plugins and mods, here are the common next steps:

- **Tune performance** — Review [JVM flags](/configuration/jvm-flags) to set appropriate heap size and garbage collection settings for your hardware.
- **Configure Arclight** — The [Arclight configuration reference](/configuration/arclight-config) covers options specific to the Bukkit integration.
- **Understand compatibility** — Not every plugin or mod works perfectly. Read [plugin compatibility](/compatibility/plugins) and [mod compatibility](/compatibility/mods) to learn about known limitations, and check [known issues](/compatibility/known-issues) if something is not working as expected.
